# North-star baseline (frozen 2026-10-03)

This is the starting point of the north-star programme. It changes nothing in `evidence/release/phase1*` or
`evidence/release/phase2/`. Machine-readable hashes:
- `CANDIDATE-HASHES.txt`: commits, trees, `git archive` hashes, every workflow file, the candidate artefacts, the
  conformance runners, and the evidence tree ids.

  the Permit token vectors.
- `../release/north-star/ECOSYSTEM-MAP.json`: per repository; generated by `collect_ecosystem_map.py`.
